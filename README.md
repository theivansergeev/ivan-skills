# Скиллы Ивана Сергеева

Готовые ИИ-сотрудники для Claude Code: для учеников вайбкодинга и вайбмаркетинга.
Работает в Claude Code внутри VS Code (расширение) и в терминале.

## Как установить (рекомендуется)

Открой Claude Code и введи две команды по очереди, прямо как есть, со слешем:

```
/plugin marketplace add theivansergeev/ivan-skills
/plugin install raspakovka@ivan-skills
```

Это родной способ Claude Code: безопасно, работает на macOS, Linux и Windows, ничего качать вручную не нужно. После установки перезапусти Claude Code (или введи `/reload-plugins`), и скилл подхватится сам.

## Запасной способ (если команды /plugin нет)

Выполни в терминале одной строкой:

```
curl -fsSL https://raw.githubusercontent.com/theivansergeev/ivan-skills/main/install.sh | bash
```

Скилл встанет в `~/.claude/skills/`, перезапускать ничего не нужно. Способ требует доверять источнику и запускать скрипт вручную, поэтому основной путь выше через `/plugin`.

## Как вызвать

Просто напиши Claude:

```
распакуй меня
```

или командой `/raspakovka-novichka`.

## Что внутри

| Скилл | Что делает |
|---|---|
| **Распаковка новичка** | Задаёт простые вопросы про тебя и на выходе показывает твои скрытые активы плюс что тебе можно продавать. Работает с чистого листа, ничего загружать не нужно. |
